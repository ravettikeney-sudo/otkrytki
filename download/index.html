Как установить на Android

Нажмите «Скачать для Android» и откройте скачанный файл otkrytki.apk.

Телефон спросит, можно ли устанавливать приложения из браузера. Нажмите «Настройки» → «Разрешить» и вернитесь назад.

Нажмите «Установить». Иконка «Открытки» появится среди приложений. Дальше обновления приходят сами.

Предупреждение «файл может быть опасен» Android показывает для любого приложения не из Google Play. «Открытки» не просят доступа к контактам, фото, сообщениям и местоположению.

На iPhone: откройте сайт приложения в Safari, нажмите «Поделиться» → «На экран „Домой“». Иконка появится как у обычного приложения.
