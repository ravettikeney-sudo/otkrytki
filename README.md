# Открытки

Красивые открытки с именем за минуту: день рождения, Новый год, 8 Марта, доброе утро и другие поводы. Открытки рисуются прямо в приложении, отправляются картинкой или ссылкой в WhatsApp, Telegram, VK, Viber и Одноклассники.
